# Private Access & NDA

This repository publishes a public evidence package for independent verification and review.

The public materials in this repository are intentionally limited to observable behavior, reproducibility artifacts, summaries, and supporting documentation.

## Private Runtime Scope

The following components are not part of the public evidence package and are not released under the public license:

- private sovereign runtime core.
- internal orchestration logic.
- agent coordination mechanisms.
- recovery internals.
- deployment infrastructure.
- memory architecture.
- arbitration systems.
- model weights.
- proprietary runtime behavior.
- non-public experimental systems.
- any other NDA-restricted component.

## Access Terms

Access to excluded materials is available only under a separate written agreement or NDA.

Any such access must be granted explicitly in writing and does not arise from possession of the public evidence package.

## No Public Disclosure

The public evidence package must not be used to infer, reconstruct, or disclose private runtime internals.

The public materials are intended for external verification of observable behavior only.

## Scope Boundary

If a component is not explicitly included in the public evidence package, it is excluded from public release by default.

Public access to the repository does not grant:
- source disclosure.
- architecture disclosure.
- recovery mechanism disclosure.
- arbitration disclosure.
- deployment disclosure.
- private operational details.

## Relationship to the Public License

This document supplements the Sovereign Runtime Public Evidence Package License.

If there is any conflict between the public license and a separate written NDA or access agreement for non-public materials, the separate written agreement controls for those materials.
